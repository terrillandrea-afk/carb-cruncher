# carb-cruncher
Carb Cruncher- simple carbohydrate and meal companion

## Installable app

The current app page is `index copy.html`. It now includes a web app manifest, app icons, and a service worker for offline access to the app shell and bundled images. The browser must open the page from a secure website (`https://`) or a local development server; opening the HTML file directly with `file://` does not enable installation or offline caching.

After publishing the folder to an HTTPS website, open the page in a supported browser and use its **Install app** or **Add to Home Screen** command. Recipes and preferences continue to be stored in that browser on that device. Recipe photos hosted by other websites still need an internet connection.
